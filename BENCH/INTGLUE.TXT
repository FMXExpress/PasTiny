PasTiny all-integer engine - 2026-11-25
=======================================

Same environment and method as README.TXT here: DOSBox-X, normal core,
cputype=386, cycles=50000 (fixed), 16 MB, BMRUN.EXE timing the whole
program (start-up, model load, answers).  One run each.  Both programs
were built from the same source with Turbo Pascal 7:

  TNYINT  TPC /B TINY.PAS            everything in whole numbers
  TNYOLD  TPC /B /DOLDGLUE TINY.PAS  integer dot products, floating
                                     point between them (the engine
                                     measured as "TP7 integer ASM" in
                                     README.TXT)

FPU DISABLED (OFF.CON)
  one question (what is 7 times 8), 34 tokens
    TNYINT   RUN 1 MS 2966    11.46 tokens/second
    TNYOLD   RUN 1 MS 17353    1.96
  five questions, 189 tokens
    TNYINT   RUN 1 MS 15653   12.07
    TNYOLD   RUN 1 MS 96761    1.95
  start-up and loading alone (quit as the only input)
    TNYINT   RUN 1 MS 262

FPU ENABLED (ON.CON), five questions, 189 tokens
    TNYINT   RUN 1 MS 15617   12.10
    TNYOLD   RUN 1 MS 15327   12.33

Answers: the 60 reference questions give the reference answers in the
TNYINT, TNYOLD, FLOATMATH and NOASM builds under DOS, and in the Free
Pascal int, float, debug and noasm builds on the host.

These are emulator comparisons, not physical Pocket386 measurements.
