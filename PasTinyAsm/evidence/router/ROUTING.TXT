Host build of the same source.  2,000 requests of each kind; a request is right
when it is sent to the class it belongs to.

  new        wordings no expert was trained on; the word lists had been mended on
             them, so the shipped router was trained on them too
  fresh      wordings written after everything else, new to lists and router alike
